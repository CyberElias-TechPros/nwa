# ADR — Template

Each ADR is a short markdown file in this directory. Filename: `NNN-slug.md`.

Sections:
- Date / Owner / Status (Proposed, Accepted, Superseded-by-ADR-NNN)
- Context — what problem, what constraints
- Decision — what we chose, in concrete terms
- Consequences — what this makes easier and harder
- Reconsider triggers — what evidence would make us revisit this
